# The Sugar and Ketone Storybook

An illustrated storybook for a 10-year-old with type 1 diabetes. It explains how high blood sugar leads to DKA (diabetic ketoacidosis) and how insulin, water and exercise help, with a check question and a pop quiz on every page.

Open `index.html` in any browser, or read it online via GitHub Pages.

This storybook explains how things work. A child's doctor and diabetes team's plan always comes first.
